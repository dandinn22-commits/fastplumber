# אינסטלטור ברגע – אתר

אתר PHP לעסק אינסטלציה, באותו מבנה ועיצוב של אתרי הצבע: דף בית, 13 דפי ערים, 4 מדריכים, דף תודה, נגישות, פרטיות ו־404.

## מה צריך לשנות לפני שעולים לאוויר
הכול בקובץ אחד: `includes/config.php`
- **טלפון ווטסאפ** – כרגע מספר זמני (050-000-0000). מחליפים בארבע השורות של PHONE ו־WA_NUMBER.
- **SITE_URL** – הכתובת המלאה של האתר, למשל `https://example.co.il`.
- **MAIL_FROM** – מומלץ כתובת על הדומיין (למשל `leads@example.co.il`), כדי שמיילי הלידים לא ייפלו לספאם.
- **GOOGLE_ADS_ID / GA4_ID / ADS_LABELS** – כשיש קמפיין.
- **REVIEWS** – רק ביקורות אמיתיות. כל עוד הרשימה ריקה, חלק הביקורות לא מוצג.

## העלאה להוסטינגר
1. בהוסטינגר: Websites → האתר → **Git** (או File Manager).
2. מחברים את הריפו `dandinn22-commits/fastplumber`, ענף `main`, לתיקייה `public_html`.
3. מוודאים שגרסת PHP היא 8.0 ומעלה.
4. נכנסים לאתר ושולחים טופס בדיקה – הליד מגיע למייל ונשמר גם בקובץ `data/leads.csv` בשרת (חסום לגישה מבחוץ).

## איך הלידים עובדים
הטפסים שולחים ל־`lead.php`, שבודק את המספר, שומר שורה ב־`data/leads.csv` ושולח מייל ל־`LEAD_EMAIL`. אם השליחה נכשלת, הלקוח מקבל קישור לשלוח את הפרטים בווטסאפ.

## מבנה
- `includes/` – הגדרות ותבניות משותפות (חסום לגישה מבחוץ)
- `includes/cities.php` – הטקסט המקומי של כל עיר
- `guides/` – המדריכים
- `assets/` – עיצוב, סקריפטים ותמונות
- `sitemap.xml` ו־`robots.txt` נוצרים אוטומטית (דרך `.htaccess`)
